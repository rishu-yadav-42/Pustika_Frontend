# Pustika Frontend - User Interface & Design System

Responsive, glassmorphism UI templates, stylesheets, and client-side JavaScript controllers for the **Pustika** E-Book & Audiobook Platform.

## 🎨 Features & Technologies

- **Bootstrap 5 & Vanilla CSS**: Custom glassmorphism cards, dark/light theme engine, bilingual English/Hindi toggle.
- **Interactive Readers & Players**: Full screen reader mode (Sepia, Night, Light themes) and audio player timeline scrubber.
- **Admin Dashboard**: Full CRUD interface for PDF extraction, chapter management, and audio generation.
